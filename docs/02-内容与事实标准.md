# 内容与事实标准

本文件约束所有编辑行为。与正文冲突时，以本文件为准。

## 1. 语气

- 第二人称，直接、克制，不推销。可以写"你很可能不需要注册公司"。
- 不使用"最佳""唯一""保证""100% 通过""官方指定"。
- 不假装中立：有明确的风险判断就直说，但把判断依据写出来。
- 不写"请联系我们"，站内没有联系方式表单，只有纠错邮箱。

## 2. 事实的四条规则

1. **每个数字带日期与口径**。价格写人民币区间（如"¥8,000–25,000/年"），并注明是全国经验值还是某城市报价。
2. **每条规则带出处**。写法律/部门规章/登记系统的名称与生效时间，例如"《公司法》（2023 年修订，2024-07-01 施行）第四十七条"。
3. **不确定就写成不确定**。"各园区执行口径不同，签约前让代理给出书面承诺"优于编一个精确数字。
4. **时效性写进正文**。税收优惠、负面清单版本、过渡期截止日必须直接出现在句子里，不能只放在页脚。

## 3. 引用与链接

- 只链接能直接核对的官方来源：国家企业信用信息公示系统（gsxt.gov.cn）、国家税务总局、国家市场监督管理总局、地方政府服务网。
- 不链接代办机构、律所营销页、论坛帖作为事实依据。
- 站内互链优先：指南 → 框架章节 → 工具 → 城市/行业页。

## 4. 指南模板

每篇指南固定结构：

1. 一句话结论（frontmatter `answer`，渲染为 answer 框）。
2. 适用与不适用（谁该读、谁可以跳过）。
3. 判断表或费用表（管道表格）。
4. 操作步骤（编号列表）。
5. 常见错误 / 红旗（`:::warn` 或 `:::kill`）。
6. 何时找专业人士（明确触发条件）。
7. 复核日期与免责声明（由布局自动渲染）。

标题层级只用 `##` 和 `###`；`#` 保留给页面标题。

## 5. 术语表

每个词条：中文、拼音、英文、分类、一句话定义、相关指南链接。定义不超过两句，不重复正文论证。分类固定为 Structure / Access / Money / People / Compliance / Exit。

## 6. 行业与城市数据

- 行业条目必须回答：外资能否做（Open / 需牌照 / 限制 / 禁止）、股权上限、牌照名称、典型时间线、一条"现实提醒"。
- 城市条目必须回答：注册地址价格带、开户难度、工作许可与社保、三个具体园区/区域、三条本地风险。
- 两者都不写"排名"，只写差异与适用场景。

## 7. 复核流程

1. 改动法规相关数字前，先在官方来源确认生效日期。
2. 改完运行 `python build.py && python check.py`。
3. 更新页面 frontmatter 的 `updated` 日期。
4. 涉及结论变化的，在 About 页的更正记录里加一行（日期 + 改了什么 + 为什么）。
